# PROJECT_IDENTITY.md

Project name: Seoul Ink Booking

This project is a standalone MVP for foreigner-friendly tattoo booking support in Seoul.

It is not:

- a Korean domestic tattoo marketplace clone
- a mobile app
- a full payment platform
- a real-time chat product
- a nationwide search platform
- a project connected to engineering, tunnel, CAD, or BIM work

## MVP Purpose

Collect foreigner booking demand data and manually match booking leads to available tattoo artists.

## Primary Test Studio

Ethnic House Sillim

## Initial Customer

Foreigners visiting Korea who want small tattoos, lettering, fine-line tattoos, or Korea-trip memory tattoos.

## Initial Language

English only. Japanese and Chinese can be added after demand is validated.
