# GitHub Workflow

Repository: `jspark91/PASSIVE-INCOME`

## Branching

- `main`: deployable baseline
- `feature/booking-form`: booking request work
- `feature/admin-leads`: admin lead workflow
- `feature/tracking`: GA4, Meta Pixel, UTM tracking

## Local Commands

```bash
npm install
npm run lint
npm run typecheck
npm run build
```

## Environment Variables

Use `.env.example` as the source of truth.

Never commit `.env.local`.
